# Master Repository Maintenance & Secure FTP Distribution

## What it is
A project case study and technical SOP documenting the process for maintaining a master reprint repository in a publishing environment — synchronizing individual chapters, front/back matter, and final archives, then securely distributing them to external print vendors via FTP.

## Why this sample
This piece is structured in two parts, intentionally written for two different audiences:
- **Project summary** (business problem, solution, impact) — for a reader who needs the "why" without technical detail
- **Step-by-step SOP** — for the person who needs to execute the process itself

This dual-audience structure reflects real documentation practice: the same process often needs both an executive-level explanation and an operational how-to.

## Skills shown
- Case-study / project documentation writing (problem → solution → impact)
- Technical SOP writing for PDF manipulation workflows (Adobe Acrobat)
- Secure credential and access documentation (FTP protocols, login procedures)
- Cross-functional writing: translating a complex production workflow for both technical and non-technical readers

## Note
All network paths, server locations, and authentication credentials have been anonymized to protect the source organization's infrastructure.
